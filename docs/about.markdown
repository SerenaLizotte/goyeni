This is the build log for **Goyeni**, a human-first career and hiring marketplace built without AI matching or algorithmic gatekeeping.

Goyeni is also my portfolio project — a way to show, transparently, what it actually looks like to build real, working software using AI-assisted development tools. That includes the working parts and the messy ones: real bugs, real debugging sessions, and real decisions about where AI assistance belongs and where it doesn't.

**Project repository:** [github.com/SerenaLizotte/goyeni](https://github.com/SerenaLizotte/goyeni)

I'm Serena Lizotte, a Platform Architect and quality engineering leader with 25+ years across healthcare, fintech, defense, telecom, and SaaS. This blog is where I document the Goyeni build as it happens.
